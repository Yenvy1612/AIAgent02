# Knowledge Base status

`kb_manifest/sources.csv` contains the candidate/reference list from the design. Review state and rights state are separate fields. A source is eligible only when **both** `review_status=approved` and `license_status=approved` and an exact local file is available. `kb_manifest/source_review.md` records evidence, scope, page versions, and unresolved rights questions. A rights decision never counts as clinical/content approval.

The local corpus is organized under `data/kb/candidates/` by publisher; `GUIDE.md` lists the decision for each file and `data/kb/rejected/` holds license-blocked, superseded, and duplicate files. QĐ 5481 (KB-01) and its amendment QĐ 1353 (KB-01A) are in `A_Bo_Y_Te_Viet_Nam/`. The pair's current-validity status and amendment mapping still need reviewer confirmation; the available official-site evidence does not establish which instrument is currently applicable for every provision. `kb_manifest/document_metadata.json` records the relationship, and chunks from amended sections carry an amendment flag. The supplied `tài liệu KB.docx` is a source catalog, not a vetted corpus. CDC text-only reuse terms have been verified for KB-25 and KB-27, and WHO's publication license covers WHO-authored text in KB-18, KB-30A, and KB-30B. A candidate local copy of KB-18 is staged, but it and the other sources still need content review. NIDDK entries KB-28 and KB-29 remain out of scope pending clarification of their reuse caveat; their pages were last reviewed in 2021 and 2017. On 2026-11-04 the project owner approved 16 of these sources by blanket decision, and the local index was built from them; `kb_manifest/source_review.md` records the limits of that decision. Statements above about candidate status describe the review before that decision.

`backend/app/rag/loader.py` extracts text and page/section metadata from PDFs and Trafilatura snapshots; `chunker.py` splits semantically by heading, paragraph, and sentence while keeping tables and criterion/exception pairs intact. Chunks carry document version, section, population, language, content hash, active state, and amendment metadata. The ingest script stores these fields in `data/kb/index.json` and refuses unapproved rows. `scripts/rebuild_kb.py` rebuilds the local index and pgvector table only when there are approved chunks; with the current empty approved corpus it leaves the vector store unchanged. Review extraction and citation metadata before use.

Chunking targets 350–600 tokens with 70-token overlap (allowed range 60–80). When `DIACARE_BGE_M3_MODEL_PATH` points to an available local tokenizer, ingest uses that tokenizer; otherwise it records and uses a deterministic Unicode word/punctuation estimate. The current environment has no local BGE model and no approved content has been chunked, so no corpus-specific token count is claimed. Page-local citation boundaries can leave a short final chunk, and an indivisible table can exceed the upper target; both preserve page attribution and table integrity.

Retrieval supports two paths. The offline default uses BM25 and character n-gram TF-IDF. When the optional FlagEmbedding stack and PostgreSQL with pgvector are configured, it embeds with local BGE-M3, searches approved payloads in pgvector by exact cosine distance and BM25 locally, fuses ranks with RRF, then applies `bge-reranker-v2-m3`. If any neural/vector component is unavailable, search falls back to the offline path. The dense score threshold is configurable and requires calibration against a reviewed query benchmark.

`scripts/index_vectors.py` and `scripts/rebuild_kb.py` index only chunks whose review and license states are both approved. `rebuild_kb.py` replaces the table in one transaction, so a failed rebuild keeps the previous rows. pgvector results are intersected with the current approved local index before they can become evidence, and citation checks live in `backend/app/rag/citations.py`. The 30-question set is `evaluation/rag/gold_questions.json`; `scripts/evaluate_kb.py` is the SADD-facing entry point and retains `evaluate_rag.py` as a compatibility implementation. `docs/EVALUATION_REPORT.md` holds the current measurements.

## Ingest rules added 2026-11-04

- `content_sha256` is mandatory for an approved source. A source that fails to load is blocked alone and contributes no partial chunks.
- `document_metadata.json` may set `exclude_pages`, `topic_by_page`, `text_replacements`, and `is_active`. A `text_replacements` entry that does not match exactly once blocks the source, so amended wording cannot silently survive. KB-01 PDF page 39 uses this for QĐ 1353.
- Diagonal digital-signature stamps are removed at extraction. Pages that are image-only, or that contain runs from a font with no Unicode map, are skipped and listed under `pages_needing_manual_review`; those font runs lose clinical numbers, so they are not decoded.
- Headings are detected per line and section titles carry across pages.

## Retrieval refusal

Local BM25/TF-IDF scores are relative to the best chunk, so an unrelated query used to score near 1. An IDF-weighted term-coverage threshold was tried and rejected: accent-free Vietnamese syllables match almost anywhere, and "Cách trồng hoa hồng trong chậu?" reached coverage 1.0. Local mode now uses the deterministic scope check in `backend/app/rag/scope.py`. Neural mode drops results under `DIACARE_RAG_MIN_RERANK_SCORE`; the default of 0 is **not calibrated yet**. Run `scripts/calibrate_rag_thresholds.py --neural` against a dry-run collection to choose it.

Excerpts containing medication doses are dropped from a chat answer individually, because one such excerpt previously made the output guard discard the whole response.
